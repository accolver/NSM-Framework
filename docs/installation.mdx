## Complete Installation Guide

### 1. Install Core Package

The `nsm-core` package contains all the essential functionality:

```bash
npm install nsm-core
```

### 2. Install Optional Packages

Depending on your use case, you may want additional packages:

<CodeGroup>
  ```bash React Integration
  npm install nsm-react
  ```

  ```bash Vue Integration
  npm install nsm-vue
  ```

  ```bash Testing Utilities
  npm install -D nsm-testing
  ```

  ```bash Development Tools
  npm install -D nsm-devtools
  ```
</CodeGroup>

### 3. TypeScript Configuration

If using TypeScript, add NSM types to your `tsconfig.json`:

```json tsconfig.json
{
  "compilerOptions": {
    "strict": true,
    "moduleResolution": "node",
    "esModuleInterop": true,
    "skipLibCheck": true,
    "target": "ES2022",
    "lib": ["ES2022", "DOM"],
    "types": ["nsm-core"]
  },
  "include": ["src/**/*"],
  "exclude": ["node_modules", "dist"]
}
```

### 4. Environment Setup

Create a `.env` file for configuration:

```bash .env
# Nostr Configuration
NOSTR_PRIVATE_KEY=your-private-key-here
NOSTR_RELAYS=wss://relay.damus.io,wss://nos.lol,wss://relay.snort.social

# Development Settings
NSM_DEBUG=true
NSM_LOG_LEVEL=info

# Optional: Custom relay settings
NSM_RETRY_ATTEMPTS=3
NSM_CONNECTION_TIMEOUT=30000
```

<Warning>
  Never commit private keys to version control! Use environment variables and add `.env` to your `.gitignore`.
</Warning>

## Framework Integrations

### React Integration

For React applications, install the React adapter:

```bash
npm install nsm-react
```

Basic React setup:

```tsx App.tsx
import React from 'react';
import { NSMProvider, useNSM } from 'nsm-react';
import { counterMachine } from './machines/counter';

function CounterComponent() {
  const { state, sendEvent } = useNSM();

  return (
    <div>
      <h2>Count: {state.context.count}</h2>
      <button onClick={() => sendEvent({ type: 'INCREMENT' })}>
        +1
      </button>
    </div>
  );
}

function App() {
  return (
    <NSMProvider
      machine={counterMachine}
      config={{
        nostrConfig: {
          relays: process.env.NOSTR_RELAYS?.split(',') || [],
          privateKey: process.env.NOSTR_PRIVATE_KEY
        },
        roomId: 'my-app-room'
      }}
    >
      <CounterComponent />
    </NSMProvider>
  );
}

export default App;
```

### Vue Integration

For Vue applications:

```bash
npm install nsm-vue
```

```vue App.vue
<template>
  <div>
    <h2>Count: {{ state.context.count }}</h2>
    <button @click="sendEvent({ type: 'INCREMENT' })">+1</button>
  </div>
</template>

<script setup>
import { useNSM } from 'nsm-vue';
import { counterMachine } from './machines/counter';

const { state, sendEvent } = useNSM(counterMachine, {
  nostrConfig: {
    relays: import.meta.env.VITE_NOSTR_RELAYS?.split(',') || [],
    privateKey: import.meta.env.VITE_NOSTR_PRIVATE_KEY
  },
  roomId: 'my-app-room'
});
</script>
```

### Next.js Setup

For Next.js applications, add this configuration:

```javascript next.config.js
/** @type {import('next').NextConfig} */
const nextConfig = {
  experimental: {
    serverComponentsExternalPackages: ['nsm-core']
  },
  webpack: (config, { isServer }) => {
    if (!isServer) {
      config.resolve.fallback = {
        ...config.resolve.fallback,
        crypto: false,
        stream: false,
        buffer: require.resolve('buffer')
      };
    }
    return config;
  }
};

module.exports = nextConfig;
```

## Verification

Verify your installation by creating a simple test:

```typescript verify-installation.ts
import { createNSMClient, createMachine } from 'nsm-core';

const testMachine = createMachine({
  id: 'test',
  initial: 'idle',
  states: {
    idle: {
      on: {
        START: { target: 'active' }
      }
    },
    active: {}
  }
});

async function verifyInstallation() {
  try {
    const client = createNSMClient({
      machine: testMachine,
      nostrConfig: {
        relays: ['wss://relay.damus.io'],
        privateKey: 'test-key'
      },
      roomId: 'verification-test'
    });

    console.log('✅ NSM Framework installation verified!');
    console.log('Current state:', client.getState().value);

    return true;
  } catch (error) {
    console.error('❌ Installation verification failed:', error);
    return false;
  }
}

verifyInstallation();
```

Run the verification:

```bash
npx tsx verify-installation.ts
```

## Troubleshooting Installation

<AccordionGroup>
  <Accordion title="Node.js Version Issues">
    **Error**: `Unsupported Node.js version`

    **Solution**:
    - Update Node.js to version 18 or later
    - Use a Node.js version manager like `nvm`:
      ```bash
      nvm install 20
      nvm use 20
      ```
  </Accordion>

  <Accordion title="Package Installation Errors">
    **Error**: `npm ERR! peer dep missing`

    **Solution**:
    - Clear package cache: `npm cache clean --force`
    - Delete `node_modules` and `package-lock.json`
    - Reinstall: `npm install`
    - Install peer dependencies manually if needed
  </Accordion>

  <Accordion title="TypeScript Compilation Issues">
    **Error**: `Cannot find module 'nsm-core'`

    **Solution**:
    - Ensure `@types/node` is installed: `npm install -D @types/node`
    - Add NSM types to `tsconfig.json` as shown above
    - Restart your TypeScript language server
  </Accordion>

  <Accordion title="WebSocket/Crypto Issues">
    **Error**: `crypto is not defined` or `WebSocket is not defined`

    **Solution**:
    - Add polyfills for browser environments
    - Update your bundler configuration (webpack, Vite, etc.)
    - See framework-specific setup guides above
  </Accordion>
</AccordionGroup>
