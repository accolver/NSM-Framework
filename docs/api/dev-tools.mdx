# NSM Dev Tools

The NSM Dev Tools package provides essential development utilities for building, debugging, and testing NSM applications. It includes debugging helpers, state inspection tools, and development server utilities.

## Installation

```bash
npm install @nsm/dev-tools
```

## Quick Start

```typescript
import { enableDevTools } from '@nsm/dev-tools';

// Enable development tools globally
enableDevTools({
  logging: true,
  inspector: true,
  timeTravel: true
});

console.log('NSM development tools enabled');
```

## Core Features

<Note>
The NSM Dev Tools package is currently in active development. The current implementation provides a foundation that will be expanded with comprehensive debugging and inspection utilities.
</Note>

### Development Mode

The dev tools package provides utilities for enabling enhanced development experience:

```typescript
import '@nsm/dev-tools';
```

## Development Utilities

### State Inspector

Visual inspection tool for NSM state machines and application state.

State inspection will be available through the developer dashboard.
Currently integrated with the NSM Client SDK for real-time debugging.

### Event Logging

Comprehensive logging system for NSM protocol events.

Event logging is built into the NSM Client for development.
Logs all NSM protocol events including definitions, interactions, and state updates.

### Time Travel Debugging

Ability to step through state machine history and replay events.

Time travel debugging integrated with XState inspector.
Allows developers to step through state machine execution.

## Integration with NSM Applications


## Testing Utilities

### Mock NSM Client

For testing applications without network dependencies:

```typescript
import { createMockNSMClient } from '@nsm/dev-tools/testing';

const mockClient = createMockNSMClient({
  applications: [
    {
      identifier: 'test-app',
      name: 'Test Application',
      initialState: { count: 0 }
    }
  ]
});

// Use in tests
expect(mockClient.discoverApplications()).resolves.toHaveLength(1);
```

### Event Builders

Utilities for creating test events:

```typescript
import {
  buildDefinitionEvent,
  buildInteractionEvent,
  buildStateUpdateEvent
} from '@nsm/dev-tools/testing';

const testDefinition = buildDefinitionEvent({
  identifier: 'test-machine',
  name: 'Test State Machine',
  initialState: { value: 'idle' }
});

const testInteraction = buildInteractionEvent({
  action: 'START',
  payload: { userId: 'test-user' }
});
```

### Test Helpers

Assertion helpers for NSM applications:


## Integration Examples

### React Application with Dev Tools

```typescript
import React from 'react';
import { NSMClient } from '@nsm/client';
import { DeveloperDashboard } from '@nsm/dev-tools';

function App() {
  const [client, setClient] = React.useState<NSMClient | null>(null);

  React.useEffect(() => {
    const nsmClient = new NSMClient({
      relayUrls: ['wss://relay.damus.io'],
      privateKey: process.env.REACT_APP_NOSTR_PRIVATE_KEY,
      debug: process.env.NODE_ENV === 'development'
    });

    nsmClient.connect().then(() => {
      setClient(nsmClient);
    });

    return () => nsmClient.disconnect();
  }, []);

  return (
    <div className="app">
      <header>
        <h1>My NSM Application</h1>
      </header>

      <main>
        {client ? (
          <MyNSMComponents client={client} />
        ) : (
          <div>Connecting to NSM network...</div>
        )}
      </main>

      {/* Development tools - only show in development */}
      {process.env.NODE_ENV === 'development' && client && (
        <DeveloperDashboard
          client={client}
          position="bottom-right"
          defaultTab="inspector"
        />
      )}
    </div>
  );
}

function MyNSMComponents({ client }: { client: NSMClient }) {
  // Your NSM application components
  return <div>NSM Application Content</div>;
}

export default App;
```

### Node.js Development Server

```typescript
import { NSMClient } from '@nsm/client';
import { enableServerDevTools } from '@nsm/dev-tools/server';

const client = new NSMClient({
  relayUrls: ['wss://relay.damus.io'],
  privateKey: process.env.NOSTR_PRIVATE_KEY,
  debug: true
});

// Enable server-side development tools
enableServerDevTools({
  client,
  port: 3001, // Dev tools dashboard port
  logging: {
    level: 'debug',
    format: 'json'
  }
});

await client.connect();
console.log('NSM development server started');
console.log('Dashboard available at: http://localhost:3001');

// Your server application logic
const app = await client.loadApplication('my-server-app');
if (app) {
  console.log('Loaded application:', app.name);

  // Subscribe to events with development logging
  client.subscribeToApplication('my-server-app', {
    onInteraction: (interaction) => {
      console.log('📥 Interaction:', interaction);
    },
    onStateUpdate: (update) => {
      console.log('🔄 State Update:', update);
    }
  });
}
```

## Troubleshooting

### Common Development Issues

1. **Dev tools not loading**
   ```typescript
   // Ensure dev tools are imported
   import '@nsm/dev-tools';

   // Check environment
   console.log('NODE_ENV:', process.env.NODE_ENV);
   ```

2. **Dashboard not appearing**
   ```typescript
   // Verify development mode
   if (process.env.NODE_ENV === 'development') {
     console.log('Development mode enabled');
   }

   // Check React integration
   {process.env.NODE_ENV === 'development' && <DeveloperDashboard />}
   ```

3. **Events not logging**
   ```typescript
   // Enable debug mode on NSM client
   const client = new NSMClient({
     debug: true, // Ensure debug is enabled
     // ... other config
   });
   ```
