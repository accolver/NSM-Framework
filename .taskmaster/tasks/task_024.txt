# Task ID: 24
# Title: Create NSM Framework Landing Page
# Status: pending
# Dependencies: 1, 3, 5, 23
# Priority: medium
# Description: Build a standalone React SPA landing page in the monorepo apps/landing-page directory using Vite + Bun + TypeScript, featuring hero section, developer/user-focused content, live demo integration, and modern UI with semantic color tokens.
# Details:
This task creates a comprehensive marketing landing page for the NSM Framework that serves as the primary entry point for developers and users interested in the platform.

**1. Project Setup and Structure**:
- Create `apps/landing-page/` directory following existing Turborepo monorepo patterns from apps/nsm-browser
- Initialize package.json with Vite + React + TypeScript + Bun configuration, similar to existing apps but optimized for static build
- Configure Vite for static HTML output targeting GitHub Pages deployment with proper base path handling
- Set up TailwindCSS with semantic color token system (--color-success, --color-danger, --color-warning) instead of hardcoded values
- Integrate ShadCN/UI components using the Ocean Breeze theme (bunx shadcn@latest add https://tweakcn.com/r/themes/ocean-breeze.json)
- Configure TypeScript with strict mode and proper path aliases for component imports

**2. Landing Page Content Architecture**:
- **Hero Section**: Compelling headline highlighting NSM's value proposition ("Build Censorship-Resistant Apps on Nostr"), subheading explaining the framework's benefits, and prominent CTAs for GitHub star and live demo
- **Developer-Focused Section**: Technical benefits section showcasing 0% platform fees, deterministic state machines, multi-user collaboration, and getting started guide with code examples
- **User-Focused Section**: End-user benefits emphasizing data sovereignty, censorship resistance, and application portability across NSM-compatible clients
- **Live Demo Integration**: Embedded iframe or component showcasing the Wordle POC from Task 5, demonstrating real NSM application functionality
- **Feature Showcase**: Interactive cards highlighting core framework features with technical details and use cases
- **Dual Call-to-Action Footer**: GitHub star button with current star count API integration and "Try Example Apps" linking to NSM Browser

**3. Design System and UI Implementation**:
- Implement responsive design using TailwindCSS with mobile-first approach, ensuring excellent experience across all device sizes
- Create semantic color system using CSS custom properties (success: emerald tones, danger: red tones, warning: amber tones, info: blue tones)
- Design wireframe/layout proposals using ShadCN components with Ocean Breeze theme for consistent, modern aesthetic
- Implement accessibility features including proper ARIA labels, keyboard navigation, and WCAG 2.1 AA compliance
- Create reusable component library for hero sections, feature cards, code blocks, and CTA buttons
- Optimize for performance with lazy loading, code splitting, and optimized asset delivery

**4. Analytics and Monitoring Integration**:
- Integrate PostHog analytics for static sites with proper privacy controls and GDPR compliance
- Set up conversion tracking for GitHub stars, demo interactions, and external link clicks
- Implement performance monitoring with Core Web Vitals tracking
- Configure error boundary components for graceful error handling and reporting

**5. Build and Deployment Configuration**:
- Configure Vite build process for static HTML generation with proper asset optimization
- Set up GitHub Pages deployment workflow with automatic builds on main branch updates
- Implement proper SEO meta tags, Open Graph properties, and Twitter Card support
- Configure service worker for offline capability and improved performance
- Set up build pipeline integration with existing Turborepo scripts and CI/CD

# Test Strategy:
1. **Component and Layout Testing**: Create comprehensive test suite using Vitest and React Testing Library to validate all landing page sections render correctly, responsive design works across viewport sizes, and semantic color tokens apply properly. Test ShadCN component integration and Ocean Breeze theme implementation.

2. **Interactive Feature Testing**: Test live demo integration with mock NSM applications, validate GitHub star button functionality with API mocking, and verify all CTAs redirect to correct destinations. Test form submissions and user interaction flows.

3. **Accessibility and Performance Testing**: Run automated accessibility testing using jest-axe to ensure WCAG 2.1 AA compliance, validate keyboard navigation and screen reader compatibility. Perform Lighthouse audits to verify performance scores above 90 for all Core Web Vitals.

4. **Build and Deployment Validation**: Test Vite static build process generates proper HTML output for GitHub Pages, validate asset optimization and bundle sizes meet performance budgets. Test deployment pipeline with staging environment before production.

5. **Analytics Integration Testing**: Verify PostHog analytics integration works correctly in static site context, test event tracking for key user interactions, and validate privacy controls function properly. Test error boundary functionality and monitoring integration.

6. **Cross-Browser and Device Testing**: Test landing page functionality across major browsers (Chrome, Firefox, Safari, Edge) and various device sizes. Validate responsive design implementation and ensure consistent experience across platforms.
